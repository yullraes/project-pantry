# 최초 인수 보고의 업무 사실과 규칙

## 범위

현장에서 검수와 인수 결정을 마친 뒤 시스템에 최초 인수 결과를 보고하는 업무를 다룬다. 발주는 별도 업무 영역이며, 발주와 입고 예정 내역이 주어진 것을 선행 조건으로 한다.

## 업무 사실

- 입고 한 건은 수송 차량 등이 한 번 도착해 물건을 내리는 입하 단위다. 현재는 이 입하에 사실상 송장 한 건이 대응한다.
- 공급사 송장에 기재된 물품과 수량, 실제 도착한 물품과 수량은 서로 다를 수 있다.
- 창고 담당자 또는 검사 담당자가 도착 물품의 수량과 품질을 검사하고, 전량 인수·일부 인수·전량 반송을 결정한다.
- 검수에서 확인한 상태와 인수·반송 결정은 구분한다. 불량이라는 사실이 곧 반송 결정을 뜻하지 않는다.
- 인수 보고는 어느 입하에서 무엇을 얼마나 검사했고, 무엇을 얼마나 인수하거나 반송하기로 했는지와 그 판단 근거를 나타낸다.
- 인수한 물건은 창고의 관리 책임 아래 놓인다.
- 반송 결정과 실제 반송 완료는 구분한다.

## 인수 내역의 구분

현재는 같은 상품이라도 발주 항목이 다르면 따로 추적한다. 예를 들어 당근 10kg과 당근 20kg은 인수할 때부터 각각 구분하여 보고한다. 같은 당근이라는 이유로 30kg 한 내역으로 합쳐 취급하지 않는다.

이후 적재 결과도 각각의 인수 내역과 연결되어야 한다. 발주 항목별 추적은 교체 가능한 현재 정책이다.

## 업무 규칙

### 보고 전 검수

- 한 번 입하한 물품 전부를 검수한 뒤 인수 보고와 적재로 넘어간다. 아직 도착하지 않은 발주 잔량까지 기다리지는 않는다.
- 전체 검수 후 진행은 교체 가능한 현재 정책이다.
- 송장이 없으면 검사 단계에서 진행을 거절하는 것으로 잠정 정리한다.

### 수량 정합성

각 내역은 같은 단위로 비교했을 때 다음 관계를 만족해야 한다.

`실제 도착 수량 = 인수 수량 + 반송 결정 수량`

현재 시나리오는 보류·폐기 등 다른 처분을 포함하지 않는다. 불량 수량을 반송 결정 수량과 자동으로 동일시하지 않는다.

### 접수와 거절

| 상황 | 처리 규칙 |
| --- | --- |
| 정상 보고 | 필요한 업무 정보와 수량 정합성을 확인한 뒤 인수 결과를 접수한다. |
| 필수 정보 누락 | 보고 전체를 거절한다. |
| 수량 불일치 | 보고 전체를 거절한다. |
| 중복 보고 | 같은 입고 건의 최초 인수 보고가 이미 접수되어 있으면 거절한다. |
| 기존 보고 정정 | 허용한다. 중복 보고와 정정은 구분한다. |
| 전량 반송 | 송장이 있고 다른 접수 조건을 만족하면 인수 수량이 0이어도 접수한다. |

보고가 거절되면 일부 내역만 정상 접수된 것으로 처리하지 않는다. 상황에 따라 필요한 정보를 모든 보고에 일괄 요구하지 않는다.

### 접수 결과

- 접수한 보고를 통해 도착 물품, 검수 결과, 인수·반송 결정 수량과 사유를 확인할 수 있어야 한다.
- 최초 인수 보고에서는 재고를 반영하지 않는다. 재고 반영 시점은 적재 완료다.
- 인수한 물건은 이후 적재와 적재 완료 보고의 대상이 된다.
- 전량 반송 보고의 접수는 실제 반송 완료나 입고 건의 최종 종료를 의미하지 않는다.

## 정상 흐름

1. 물건이 도착하면 공급사 송장을 바탕으로 하역한 물품을 확인한다.
2. 창고 담당자 또는 검사 담당자가 도착 물품 전부의 수량과 품질을 검사한다.
3. 인수·반송 여부와 각각의 수량을 결정한다.
4. 담당자가 그 결과를 시스템에 최초로 보고한다.
5. 시스템은 접수 조건을 만족하면 인수 결과를 접수하고, 만족하지 않으면 보고 전체를 거절한다.

## 개발자에게 위임하는 판단과 후속 범위

위에서 합의한 업무 사실과 규칙을 기준으로 설계·구현을 진행한다. 아래 미정 사항에 대한 추가 업무 판단은 개발자에게 위임하며, 별도 기획 협의를 선행 조건으로 두지 않는다.

- 상황별 필수 정보의 구체적인 조건
- 정정 허용을 전제로 한 가능 시점·범위, 과거 보고 이력 확인 필요성, 적재 또는 재고 반영 이후의 정정 처리
- 송장이 없어 현장에서 진행을 거절한 사실의 처리
- 실제 반송 처리와 전량 반송 건의 최종 종료 절차의 상세 및 구현 범위
