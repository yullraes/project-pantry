# 적재 완료 보고의 업무 사실과 규칙

## 범위

최초 인수 보고가 접수된 물건에 대해, 현장 담당자가 적재를 마치고 그 결과를 시스템에 보고하는 업무를 다룬다.

## 업무 사실

- 최초 인수 보고를 통해 인수한 물건과 수량이 확인되어 있다.
- 인수한 물건은 창고의 관리 책임 아래 있다.
- 적재 위치는 현장 담당자가 최종 결정한다. 시스템이 위치를 추천하더라도 최종 결정은 담당자가 한다.
- 적재 완료 보고는 어느 입고에서 인수한 각 내역을 실제로 어디에 얼마나 적재했는지 나타낸다.
- 보고 대상은 예정하거나 추천받은 배치가 아니라 실제 적재 결과다.

## 인수 내역과 적재 결과의 관계

인수 때 구분한 내역을 적재 결과에서도 유지한다. 현재는 같은 상품이라도 발주 항목이 다르면 따로 추적하며, 이 기준은 교체 가능하다.

| 인수한 내역 | 실제 적재 결과 |
| --- | --- |
| 당근 10kg | 위치 A에 10kg 적재 |
| 당근 20kg | 위치 B에 20kg 적재 |

위 예시는 인수 때부터 구분된 두 내역을 각각 적재한 것이다. 각 내역의 적재 수량이 해당 인수 수량과 일치해야 하며, 상품별 합계만 일치하는 것으로는 충분하지 않다.

## 업무 규칙

### 보고 단위

- 담당자는 인수한 물건의 적재를 모두 마친 뒤 전체 결과를 한 번에 보고한다.
- 시스템은 중간 적재 보고를 접수하지 않는다. 작업 중 나누어 작성하거나 임시 보관하는 화면 동작은 이번 업무 범위 밖이다.

### 접수 조건

- 해당 입고에서 인수한 내역이 빠짐없이 보고되어야 한다.
- 보고한 적재 대상은 해당 입고의 인수 내역에 해당해야 한다.
- 각 내역의 적재 수량은 해당 인수 수량과 일치해야 한다.
- 적재 위치는 유효해야 한다.

### 접수와 거절

| 상황 | 처리 규칙 |
| --- | --- |
| 정상 보고 | 접수 조건을 확인한 뒤 전체 적재 결과를 접수한다. |
| 내역 누락 | 보고 전체를 거절한다. |
| 수량 불일치 | 보고 전체를 거절한다. |
| 유효하지 않은 위치 | 보고 전체를 거절한다. |
| 중복 완료 보고 | 같은 입고 건의 완료 보고가 이미 접수되어 있으면 거절한다. |
| 완료 후 정정 | 허용한다. 중복 완료 보고와 기존 보고의 정정은 구분한다. |

### 접수 결과

- 각 인수 내역을 실제로 어디에 얼마나 적재했는지 확인할 수 있어야 한다.
- 인수한 수량 전부의 적재 결과가 접수되면 입고를 완료한다.
- 재고 반영 시점은 적재 완료다. 시스템은 적재 완료 보고를 접수하여 해당 결과를 재고에 반영한다.
- 거절한 보고를 근거로 일부 내역만 완료 처리하거나 재고에 반영하지 않는다.
- 완료 후 정정 시에는 이미 반영된 재고와 정정 결과 사이의 정합성이 유지되어야 한다.

## 정상 흐름

1. 최초 인수 보고가 접수되어 인수 내역이 확인된다.
2. 현장 담당자가 위치를 최종 결정하고 물건을 적재한다.
3. 전체 적재 작업을 마치면 각 인수 내역을 어디에 얼마나 적재했는지 한 번에 보고한다.
4. 시스템은 접수 조건을 만족하면 적재 결과를 접수하고 재고에 반영하며 입고를 완료한다. 만족하지 않으면 보고 전체를 거절한다.

## 개발자에게 위임하는 판단과 후속 범위

위에서 합의한 업무 사실과 규칙을 기준으로 설계·구현을 진행한다. 아래 미정 사항에 대한 추가 업무 판단은 개발자에게 위임하며, 별도 기획 협의를 선행 조건으로 두지 않는다.

- 위치가 유효한지 판단하는 구체적인 업무 기준
- 완료 후 정정 허용을 전제로 한 정정 범위와 이후 출고·이동 등이 발생한 경우의 처리
- 실제 반송 처리와 전량 반송 건의 최종 종료 절차의 상세 및 구현 범위

적재 위치 추천과 작업 지시 기능은 이번 보고의 범위에 포함하지 않는다.
