# 창고 내 재고 이동 시나리오

## 범위

하나의 창고 안에서 이미 재고로 관리하는 물품을 한 위치에서 다른 위치로 옮기고, 작업을 마친 뒤 실제 이동 결과를 보고하는 업무를 다룬다.

창고 간 이동과 운송 중 재고는 범위에 포함하지 않는다. 적재 완료 보고에서 최초 위치에 재고를 넣는 것은 입고 업무이며, 이 문서의 이동은 그 이후에 재고 위치를 바꾸는 업무다.

## 업무 사실

- 이동은 출발 위치의 재고를 줄이고 도착 위치의 같은 상품 재고를 같은 수량만큼 늘린다.
- 현장 담당자가 실제 출발 위치, 도착 위치와 수량을 결정한다.
- 시스템은 이동 작업을 지시하기보다 담당자가 완료했다고 보고한 실제 결과를 기록한다.
- 한 번의 이동 보고에는 함께 수행한 여러 상품의 이동 결과를 포함할 수 있다.
- 위치별 재고는 달라지지만 창고 전체 상품 수량은 이동만으로 달라지지 않는다.

## 이동 완료 보고

담당자는 이동을 마친 뒤 다음 내용을 보고한다.

- 이동 담당자와 보고 시각
- 상품
- 출발 위치와 도착 위치
- 실제 이동 수량과 단위
- 필요한 경우 이동 사유 또는 메모

보고에는 하나 이상의 이동 항목이 있어야 한다. 같은 보고에서 같은 상품·출발 위치·도착 위치의 이동은 한 항목으로 합친다.

## 접수와 재고 반영

- 상품, 출발 위치와 도착 위치는 유효해야 한다.
- 출발 위치와 도착 위치는 달라야 한다.
- 이동 수량은 0보다 커야 하며 상품의 재고 단위를 사용해야 한다.
- 출발 위치 차감과 도착 위치 증가는 함께 성공하거나 함께 실패한다.
- 이동 완료 보고, 전체 항목과 재고 반영도 한 트랜잭션에서 처리한다.
- 일부 항목만 접수하거나 한쪽 위치의 재고만 바꾸지 않는다.

현재 출고 보고와 마찬가지로 전산재고보다 많은 수량을 실제로 이동했다고 보고한 경우에도 현장 결과를 보존하기 위해 접수하고 출발 위치의 음수 재고를 허용한다. 이 경우 재고 불일치가 드러나며 후속 실사의 대상이 될 수 있다.

## 정정

접수한 이동 보고를 정정할 때 기존 기록을 수정하지 않고 전체 이동 결과를 담은 새 판을 추가한다. 시스템은 이전 유효 판과 새 판의 상품·출발 위치·도착 위치별 차이를 계산하여 재고에 반영한다.

실제로 나중에 추가 이동한 것은 정정이 아니라 새로운 이동 완료 보고다. 정정 보고와 재고 반영은 함께 성공하거나 함께 실패한다.

## 시나리오

### 1. 한 상품을 이동한 경우

1. 담당자가 당근 5kg을 위치 A에서 위치 B로 옮긴다.
2. 이동 완료 결과를 시스템에 보고한다.
3. 시스템은 위치 A의 당근을 5kg 줄이고 위치 B의 당근을 5kg 늘린다.

### 2. 여러 상품을 함께 이동한 경우

1. 담당자가 당근 5kg과 양파 3kg을 위치 A에서 위치 B로 옮긴다.
2. 두 항목을 하나의 이동 완료 보고로 제출한다.
3. 시스템은 전체 보고를 검증하고 두 상품의 위치별 재고를 함께 반영한다.

### 3. 전산재고가 부족한 경우

1. 위치 A의 당근 전산재고는 3kg이지만 담당자는 실제로 5kg을 위치 B로 옮겼다.
2. 담당자가 실제 이동 결과 5kg을 보고한다.
3. 시스템은 보고를 접수하여 위치 A를 -2kg, 위치 B를 +5kg 변경한다.
4. 음수 재고는 기존 전산재고가 현장과 달랐음을 보여주며 후속 실사로 확인한다.

### 4. 이동 보고를 정정하는 경우

1. 당근 5kg을 위치 A에서 B로 이동했다고 보고했다.
2. 실제 도착 위치가 B가 아니라 C였음을 확인한다.
3. 담당자가 전체 결과를 담은 정정 판을 제출한다.
4. 시스템은 이전 판을 보존하면서 A와 B에 반영한 효과를 되돌리고 A에서 C로 이동한 효과를 반영한다.

## 현재 범위에서 다루지 않는 내용

- 창고 간 이동
- 운송 중 위치와 운송 중 재고
- 이동 예정, 작업 지시와 담당자 배정
- 이동 중간 단계나 부분 완료 보고
- 단위 변환

## 개발자에게 위임하는 판단과 후속 범위

- 이동 사유를 필수로 받을 조건
- 전산재고 부족 이동에 경고만 할지 별도 확인을 요구할지 여부
- 한 보고에서 여러 출발 위치와 도착 위치를 허용하는 구체적인 요청 형식
- 이동 정정 이후 다른 출고나 이동이 발생했을 때 재고 정합성을 유지하는 방법
